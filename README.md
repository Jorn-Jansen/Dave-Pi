# Dave voor Raspberry Pi

Een slimme speaker zoals een Google Home: zeg **"hey Dave"** en vraag wat je wilt. Dave bedient je lampen en apparaten, zet timers
en wekkers, houdt lijsten bij en praat terug. Hetzelfde brein als [Dave voor Windows](https://github.com/Jorn-Jansen/Dave-Windows)
en [Dave voor iPhone](https://github.com/Jorn-Jansen/Dave-iPhone), maar dan zonder scherm.

De code is privé.
